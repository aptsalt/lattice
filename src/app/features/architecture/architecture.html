Hybrid Graph-RAG, end to end

Lattice is the Angular front end of a three-tier system: Angular 21 → FastAPI → Neo4j. The browser talks to one endpoint, POST /chat, and renders whatever evidence the service returns. In this public demo the service is mocked in the browser with the same contract, so everything you see is the real UI over a faithful pipeline.

Three tiers

Angular 21 this app

  • Standalone, zoneless, signals-first; OnPush everywhere.
  • Conversation list in the sidebar; every retrieval control lives in the composer.
  • Evidence panel: four subgraph views, facts, sources, Cypher, trace.
  • Swap RagEngine.chat() for an HttpClient call — nothing else changes.

FastAPI service

  • POST /chat runs the eight-stage pipeline below and streams the answer (SSE).
  • Settings per request: data source, retrieval mode, context on/off, LLM on/off.
  • Offline mode reads resolved.json, a snapshot exported from the graph.
  • Every stage is timed and logged; the trace you see is the server's own log.

Neo4j knowledge graph

  • Entities extracted from policy documents become typed nodes with provenance.
  • Full-text index on names/aliases; vector index on entity + passage embeddings.
  • Typed relations carry a confidence and the section they came from.
  • Taxonomy: World → North America → USA / MEX / CAN → policy → leave type → rule.

Why hybrid, why graph

Lexical alone

Exact on names and section numbers, blind to paraphrase ("time off" vs "annual leave").

Vector alone

Catches paraphrase, but a flat top-k of chunks cannot tell you that Canada's carryover rule overrides the global one.

Hybrid + graph

Fuse both to find the right entry points, then walk the typed relations to collect the exact rules, their overrides, the statutes behind them and the sections that prove them. The answer is composed only from that subgraph, and the subgraph is what you see in Evidence.
